# 拾光通讯录 · 手动测试清单

> 测试地址：<http://localhost:3100>  
> 当前数据：12 位联系人、4 位收藏（初始状态）  
> 建议浏览器：Chrome / Edge，桌面窗口约 1440×960；移动端用开发者工具切 390×844。

## 0. 开始之前

- 打开页面后按 `Ctrl + F5` 强制刷新一次，避免旧缓存。
- 测试会修改数据（新增、导入、收藏）。全部测完后可以让助手执行 `npm run seed` 恢复 12 条示例数据。
- 如果页面打不开，说明本机预览服务已停止；双击
  `E:\dsh\addressbook-assignment\.run\start-windows.bat` 可重新启动。

## 6. 导入 Excel（25 分）

### 6.1 使用现成样例

文件：`E:\dsh\addressbook-assignment\docs\samples\import-demo.xlsx`

初始 12 条数据下，第一次选择「合并更新」导入，预期：

| 结果 | 数量 |
|---|---|
| 新增 | 2（贾谊、王通） |
| 更新 | 2（罗峰、徐欣） |
| 跳过重复 | 0 |
| 未导入 | 1（第 6 行「错误示例」，邮箱 `not-an-email` 格式错误） |
| 导入后总数 | 14 |

检查：

1. 结果弹窗显示「4 位联系人已写入通讯录」，统计卡片为 2/2/0/1。
2. 错误列表显示「第 6 行 错误示例：邮箱地址…无效」。
3. 关闭后左侧出现贾谊、王通，收藏筛选变为 5 人（新增两位中贾谊收藏）。
4. 打开贾谊，应看到 4 条联系方式（手机、邮箱、微信、地址）。

### 6.2 再导入同一文件

### 6.3 错误与边界

| # | 操作 | 预期结果 |
|---|---|---|
| 6.3.1 | 上传 `.txt` 文件 | 被拒绝，提示仅支持 `.xlsx` |

## 7. 持久化

2. 关闭浏览器再打开 <http://localhost:3100>：数据仍在（SQLite 文件）。
3. 重启服务（关闭命令行窗口后重新运行 `.run\start-windows.bat`）：数据仍在。
